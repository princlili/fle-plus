# FLE+

**Human first. Language second.**

🔗 [fle-plus on GitHub Pages](https://princlili.github.io/fle-plus/fr/)

---

FLE+ is an approach to teaching French as a foreign language, built from observation of real learners in real situations. It does not start from levels (A1, B2...), but from a simpler question: what can this language offer someone who doesn't love it yet?

---

## What FLE+ is not

- A ready-made curriculum
- A method to apply
- A definitive answer

## What FLE+ looks for

FLE+ starts from the conviction that language is learned through action — not through correction, not through performance. Learners — in classrooms, workshops, or elsewhere — tend to engage more deeply when:

- they have a real problem to solve together
- mistakes are part of the process, without penalty
- French serves something that goes beyond the grade

At the core of FLE+ is a more ambitious question: what do you care about most, as a human being? And can you begin to think, build, or create something around that — in a language you barely master?

This is not a school exercise. It is a practice of transformation.

## Core principles (in progress)

- Genuine collaboration, not simulated
- Long-term projects rooted in real challenges
- Usefulness, even for those who don't like French
- Human first, language second
- Open to digital, analog, and hybrid forms

## What this repository documents

Observations from real learning situations (anonymized). Patterns, failures, adjustments, surprises. No claim to universality. A claim to honesty.

This project builds slowly, from the ground up.

## Tool: oral scaffolding generator

`fr/terrain/scaffolding.html` · [open live](https://princlili.github.io/fle-plus/fr/terrain/scaffolding.html)

A tool to help teachers formulate starting situations for oral dialogue between A1 learners.

**Workflow:** rough idea → anchor points → guided reformulation → follow-up prompts → projectable student card with timer.

**Designed for:** Swiss German context, adolescents, A1− to A1+.

**Requires:** a personal Anthropic API key ([get one](https://console.anthropic.com)) · estimated cost < $1/month for classroom use.

The key is entered manually each session — never saved, never in the code.
