## Actions à faire

1. **Personnaliser** les fichiers :
   - Remplacer `[Votre Nom]` par votre nom dans LICENSE-CODE.md
   - Remplacer `[votre-email@example.com]` dans CONTRIBUTING.md

2. **Commit et push** :
   ```bash
   git add LICENSE.md LICENSE-CODE.md CONTRIBUTING.md
   git commit -m "Add licenses and contribution guidelines"
   git push
   ```

3. **C'est tout** ! Ton projet est maintenant légalement protégé.
