# Contribuer à FLE+

Merci de votre intérêt pour FLE+ ! Ce projet est ouvert et accueille les contributions de toutes sortes.

## Types de contributions

### 1. Retours d'expérience
Vous avez testé une approche FLE+ dans votre classe ? Partagez votre expérience !
- Ce qui a fonctionné
- Les défis rencontrés
- Les adaptations nécessaires
- Les résultats observés

### 2. Ressources pédagogiques
- Scénarios d'activités
- Séquences complètes
- Grilles d'évaluation
- Supports de cours

### 3. Analyses et réflexions
- Critiques constructives de l'approche
- Approfondissements théoriques
- Liens avec d'autres recherches
- Propositions d'amélioration

### 4. Améliorations techniques
- Corrections du site web
- Ajout de fonctionnalités
- Traductions supplémentaires
- Optimisations

## Comment contribuer

### Option 1 : Via GitHub (pour les utilisateurs techniques)

1. **Fork** le repository
2. Créez une **branche** pour votre contribution
   ```bash
   git checkout -b ma-contribution
   ```
3. Faites vos modifications
4. **Commit** avec un message clair
   ```bash
   git commit -m "Ajout: [description de votre contribution]"
   ```
5. **Push** vers votre fork
   ```bash
   git push origin ma-contribution
   ```
6. Ouvrez une **Pull Request**

### Option 2 : Via formulaire (bientôt disponible)

Un formulaire Google sera bientôt disponible pour soumettre des contributions sans passer par GitHub.

### Option 3 : Par email

Contactez directement : [votre-email@example.com]

## Directives

### Contenu pédagogique

- ✅ Partagez des expériences réelles et concrètes
- ✅ Documentez les contextes (niveau, âge, objectifs)
- ✅ Soyez honnête sur les échecs et les réussites
- ✅ Citez vos sources si vous vous inspirez d'autres travaux
- ❌ Évitez les affirmations non étayées
- ❌ Pas de contenu plagié ou sans attribution

### Code et site web

- ✅ Testez vos modifications localement
- ✅ Respectez la structure existante
- ✅ Commentez le code si nécessaire
- ✅ Maintenez l'accessibilité (WCAG 2.1)
- ❌ Pas de dépendances JavaScript lourdes sans justification

## Licence de contribution

En contribuant à FLE+, vous acceptez que :

- **Votre contenu pédagogique** soit publié sous licence **CC BY-SA 4.0**
- **Votre code** soit publié sous licence **MIT**
- Vous serez crédité dans la section "Contributeurs" (sauf demande contraire)

## Attribution

Toutes les contributions seront créditées. Vous pouvez choisir d'apparaître :
- Sous votre nom complet
- Sous un pseudonyme
- De manière anonyme

## Questions ?

N'hésitez pas à ouvrir une **Issue** sur GitHub pour :
- Poser des questions
- Proposer des idées
- Signaler des problèmes
- Demander des clarifications

## Code de conduite

FLE+ est un espace bienveillant et respectueux. Nous attendons de tous les contributeurs :

- Respect mutuel et écoute
- Ouverture aux critiques constructives
- Valorisation de la diversité des approches
- Humilité et reconnaissance des limites de sa propre expérience

Les comportements inappropriés (harcèlement, insultes, discrimination) ne seront pas tolérés.
